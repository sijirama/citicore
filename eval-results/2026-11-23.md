# Constitution chat evaluation — 23 Nov 2026

Ten questions were run against an isolated local copy of the uploaded Constitution (697 embedded passages). Each JSONL record contains the exact model search arguments, returned passage IDs/sections/pages/excerpts, and final model answer. Four problem cases were rerun after changes; a broad rights question was run once more with a six-search budget. A public `/api/chat` request for the Chief Justice appointment also returned the expected answer and its section 231 citation after the document became published.

| Question | Search and answer review |
| --- | --- |
| Fundamental rights | Initial query was overlong and the answer cited the contents page. Focused searches plus a six-call budget returned body provisions with no contents-page citation. |
| Police arrest without a warrant | Initial answer inferred “yes” from the Constitution’s general liberty provision. Rerun correctly says the available document does not establish the specific warrant rule. The Police Act/ACJA are absent from the library. |
| Federal, state, local responsibilities | Initial run exceeded four search calls and errored. Rerun completed with four focused queries and relevant legislative/Fourth Schedule passages. |
| Defence and aviation lawmaking | Relevant Exclusive Legislative List and section 4 passages; answer cites them. |
| Local council functions | Relevant Fourth Schedule passages; answer cites them. |
| Presidential election | Section 134 passages retrieved and cited. This is a document-grounding check, not a check that the uploaded version is legally current. |
| Movement rights | Section 41 and restriction provisions retrieved and cited. |
| Chief Justice appointment | Section 231 retrieved and cited; also passed via the public API. |
| 2027 polling unit | Agent says the Constitution cannot identify an individual's polling unit. The suggestion to check INEC is practical guidance, not a lookup from the library. |
| Today's election results | No live source; agent abstains. The public handler would return its standard no-source fallback because the answer has no citations. |

All cited IDs in the reruns were present in their returned passage sets. This checks source linkage and obvious grounding issues; it is not a legal accuracy review of every sentence. The original corpus had one uploaded Constitution, so questions needing the Police Act, current INEC data, or election results remain outside coverage.
